## 📝 Problem Statement

You are given an integer N. Determine whether N is even or odd using a conditional statement.

A number is even if it is divisible by 2; otherwise, it is odd.

**Input**

The input contains a single integer:

- N — an integer whose parity needs to be determined.

**Output**

Print:

- Even if N is divisible by 2.
- Odd otherwise.

### Example 1:

**Input:**

```
4
```

**Output:**

```
Even
```

**Explanation:**

4 % 2 = 0, so 4 is divisible by 2 and is therefore even.

### Example 2:

**Input:**

```
7
```

**Output:**

```
Odd
```

**Explanation:**

7 % 2 = 1, so 7 is not divisible by 2 and is therefore odd.
