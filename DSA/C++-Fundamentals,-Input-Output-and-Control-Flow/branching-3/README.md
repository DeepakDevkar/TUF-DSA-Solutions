## 📝 Problem Statement

You are given two integers A and B.

Find and print the greater of the two numbers.

**Input**

The input contains two integers in the following order:

- A — the first integer.
- B — the second integer.

**Output**

- Print the maximum of A and B.

### Example 1:

**Input:**

```
10
100
```

**Output:**

```
100
```

**Explanation:**

Between 10 and 100, the greater number is 100.

### Example 2:

**Input:**

```
-15
20
```

**Output:**

```
20
```

**Explanation:**

Between -15 and 20, the greater number is 20.
