## 📝 Problem Statement

You are given three integers A, B, and C.

Find and print the largest among the three numbers using an if-else ladder.

**Input**

The input contains three integers in the following order:

- A — the first integer.
- B — the second integer.
- C — the third integer.

**Output**

- Print the maximum value among A, B, and C.

### Example 1:

**Input:**

```
3
7
5
```

**Output:**

```
7
```

**Explanation:**

Among 3, 7, and 5, the largest number is 7.

### Example 2:

**Input:**

```
-1
-4
-2
```

**Output:**

```
-1
```

**Explanation:**

Among -1, -4, and -2, the largest number is -1.
