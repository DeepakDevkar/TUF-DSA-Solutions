## 📝 Problem Statement

You are given a single integer N.

Read the integer from standard input and print the integer.

**Input**

The input contains a single value:

- N — an integer.

**Output**

- Print the value of N on a single line.
- Print a newline after the integer as well..

### Example 1:

**Input:**

```
5
```

**Output:**

```
5
```

### Example 2:

**Input:**

```
-90
```

**Output:**

```
-90
```

Still unsure what the problem is asking ?

Let’s go through a few more examples, step by step, to make it clearer.

### Constraints

- -100 <= N <= 100
- Input will always be a valid Integer

## 💡 Complexity Analysis

- **Time Complexity:** $\mathcal{O}(N)$
- **Space Complexity:** $\mathcal{O}(1)$
