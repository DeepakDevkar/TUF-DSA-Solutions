## 📝 Problem Statement

You are given a person's first name as a string and age as an integer.

Read the name and age from the input in the given order, then print the name and age on separate lines.

**Input:**

The input contains two values in the following sequence:

- Name: a string representing the person's first name.
- Age: an integer representing the person's age.

**Output:**

- Print the name on the first line and the age on the second line.
- Print a newline after the age as well.

### Example 1:

**Input:**

```
Raj
32
```

**Output:**

```
Raj
32
```

### Example 2:

**Input:**

```
Varun
50
```

**Output:**

```
Varun
50
```

### Constraints

- 1 <= age <= 100
- name contains all English letters (lowercase and capital both).
