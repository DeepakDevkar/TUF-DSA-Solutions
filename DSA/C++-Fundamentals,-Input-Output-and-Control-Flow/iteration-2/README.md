## 📝 Problem Statement

You are given an integer N.

Print the multiplication table of N from 1 to 10.

Each value in the table should be separated by a single space. Do not print an extra space after the last value. Print the complete table on a single line, followed by a newline.

**Input**

The input contains a single integer:

- N — the number whose multiplication table needs to be printed.

**Output**

- Print the first 10 multiples of N, starting from N × 1 and ending at N × 10.
- Separate consecutive values with a single space (no extra space after last number).

### Example 1:

**Input:**

```
5
```

**Output:**

```
5 10 15 20 25 30 35 40 45 50
```

### Example 2:

**Input:**

```
3
```

**Output:**

```
3 6 9 12 15 18 21 24 27 30
```
