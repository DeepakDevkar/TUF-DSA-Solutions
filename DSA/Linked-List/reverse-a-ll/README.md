## 📝 Problem Statement

Given the head of a singly linked list. Reverse the given linked list and return the head of the modified list.

### Example 1:

**Input:** head = [1, 2, 3, 4, 5]

**Output:** [5, 4, 3, 2, 1]

**Explanation:** The linked list is reversed by changing the direction of each link between consecutive nodes, resulting in the list [5, 4, 3, 2, 1].

### Example 2:

**Input:** head = [6, 8]

**Output:** [8, 6]

**Explanation:** The link between the two nodes is reversed, changing the list from 6->8 to 8->6.
